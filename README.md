# Onagro — MVP de teste (GitHub Pages)

Este repositório existe **apenas para hospedar, via GitHub Pages, o MVP de teste do jogo Onagro**.

Não é o repositório de desenvolvimento do jogo: aqui fica somente o build já compilado e pronto para ser servido como site estático.

## Jogar

🎮 Teste o jogo em: **https://jeanomeg.github.io/onagro/**

## Estrutura

- `docs/` — build final do jogo (HTML, JS, imagens e áudios). É a pasta publicada pelo GitHub Pages.

## Publicação

O GitHub Pages está configurado para servir a pasta `docs/` da branch principal.
Para atualizar o MVP, basta substituir o conteúdo de `docs/` pelo novo build e fazer o commit/push.

## Observações

- Não abra issues ou pull requests com alterações de código do jogo aqui.
- Os arquivos em `docs/` são gerados automaticamente pelo build e não devem ser editados manualmente.
